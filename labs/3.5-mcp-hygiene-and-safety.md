# 3.5 · ใช้ MCP อย่างปลอดภัยและประหยัด Context (5 นาที)

**สิ่งที่จะฝึก:** เข้าใจผลกระทบของข้อมูลจาก MCP ต่อขนาด Context Window (สไลด์ 13), การระบุชื่อ Tool แบบเจาะจง `#server/tool` และการปิด Tools ที่ไม่จำเป็นใน **Customizations › Tools** (สไลด์ 14)

---

## 1. เทียบขนาดข้อมูล: ส่งทั้งแคนวาส (`node-id=0-1`) vs ส่งเฉพาะ Frame (2 นาที)

เวลาคนส่งลิงก์ Figma มาให้ในแชต มักก๊อปปี้ลิงก์จากแถบ Address Bar ตอนยังไม่ได้คลิกเลือก Frame ซึ่งจะได้ `node-id=0-1` (ทั้งหน้าแคนวาส Page 1):

| สิ่งที่ส่งให้ `get_figma_data` | Node ID | ขนาดผลลัพธ์ที่ไหลเข้า Context Window | ผลที่เกิดกับ Agent |
|---|---|---|---|
| **ทั้งหน้า Page 1** | `0-1` | ผลตรวจ 2026-11-12: **412.8 KB** | ปนหลายเฟรมและข้อมูลนอกโจทย์ ผลขนาดใหญ่อาจถูกเก็บเป็นไฟล์ชั่วคราว |
| **เฉพาะ Frame Reservation** | `1439-8969` | ผลตรวจครั้งเดียวกัน: **21.4 KB** | จำกัดขอบเขตไว้ที่หน้าจอง ไม่ปนหน้า E-commerce |
| **เฉพาะ Frame Single Product** | `518-8937` | ตรวจจากผล Tool ของคุณ ไม่กำหนดตัวเลขล่วงหน้า | จำกัดขอบเขตไว้ที่หน้าสินค้า ไม่ปนหน้าจองร้านอาหาร |

ตัวเลขเป็นขนาดข้อความที่ Tool รายงานในการตรวจครั้งนั้น ไม่ใช่ค่าคงที่ จำนวน Token หรือค่าใช้จ่ายที่วัดแล้ว ใช้ผล Lab 3.3 เทียบกับตารางได้ **ไม่ต้องเรียกทั้งแคนวาสซ้ำ** โดยเฉพาะเมื่อเจอ 429

> **วิธีเอาลิงก์เฉพาะ Frame ใน Figma:** คลิกที่ชื่อ Frame บนแคนวาสหรือในแถบ Layers ซ้ายมือ → คลิกขวาเลือก **Copy/Paste as › Copy link to selection** (หรือกด `Cmd+L` บน macOS / `Ctrl+L` บน Windows) จะได้ URL ที่มี `?node-id=` ของ Frame นั้นพอดี

## 2. ระบุชื่อ Tool ด้วย `#` และปิด Tools ที่บทบาทเราไม่ได้ใช้ (2 นาที)

จากสไลด์ 14 ("Using MCP safely"):

1. **การอ้างอิงชื่อ Tool โดยตรง (`#server/tool`):**
   ในช่องแชต ลองพิมพ์ `#figma` หรือ `#get_figma_data` จะเห็นว่าสามารถระบุเจาะจงได้ว่าต้องการให้เรียก Tool ตัวไหนโดยไม่สับสนกับ Server อื่น
2. **การปิด Tools ที่ไม่ได้ใช้ (Principle of Least Privilege):**
   เปิดหน้าตั้งค่า Tools ของ Agent:
   - ใน Copilot harness: ไปที่ **Customizations › Tools** (หรือคลิกปุ่ม Tools ในช่องแชต) → ขยายกลุ่ม **`figma`**
   - ลองพิจารณาตามบทบาท:
     - สำหรับ **BA** และ **QA**: งานของเราคือ **อ่าน** โครงสร้าง Figma มาเขียน Spec / Test Cases ไม่จำเป็นต้องให้ Agent ดาวน์โหลดไฟล์รูปภาพมาเขียนลงดิสก์ → **ให้ติ๊กเอา `download_figma_images` ออก** เหลือไว้เฉพาะ `get_figma_data`
     - สำหรับ **Dev**: เมื่อดาวน์โหลดรูปเสร็จแล้ว หรือในงานที่ต้องการแก้เฉพาะ CSS ก็สามารถปิด `download_figma_images` ได้เช่นกัน

## 3. เช็กความเรียบร้อยก่อน Share-out (1 นาที)

รันคำสั่งนี้ใน Terminal (หรือดูในแถบ Source Control ของ VS Code):

```bash
git status
```

ตรวจ diff ของไฟล์ที่จะ commit ว่า **ไม่มี API Key จริง** โดยเฉพาะ `.vscode/mcp.json` หรือ `.mcp.json` หากมีไฟล์เก็บ secret ให้เอาออกจากรายการ staged และตั้ง ignore ให้ตรง path; อย่าสมมติว่า `.gitignore` กันไว้แล้ว ไฟล์ config ที่ใช้ `${input:figma-key}` แทนค่าจริงอาจติดตามใน Git ได้

**เช็กก่อนจบแล็บ**

- [ ] ทดลองติ๊กปิด Tool ที่ไม่จำเป็นใน Customizations › Tools / Configure Tools แล้วอย่างน้อย 1 ตัว
- [ ] ตรวจ diff แล้วว่าไม่มี API Key จริงในไฟล์ที่จะ commit; ถ้ามีไฟล์ลับ ยืนยันว่าไม่ถูกติดตามโดย Git
