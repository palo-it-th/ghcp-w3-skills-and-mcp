# 3.3 · เชื่อมต่อ Figma MCP Server (8 นาที)

**สิ่งที่จะฝึก:** ตั้งค่า `.mcp.json` เพื่อเชื่อมต่อ [glips/figma-context-mcp](https://github.com/glips/figma-context-mcp) (`figma-developer-mcp`), ตรวจสอบรายการ Tools (`tools/list`) และทดสอบดึงข้อมูลจริง (`tools/call`) จากหน้าจอใน Figma

---

## 1. setup `mcp.json` ที่ folder .vscode ของโปรเจกต์ (3 นาที)

ในข้อนี้เราจะตั้งค่า MCP Server แบบ `stdio` (VS Code เป็นคนรันโปรเซสผ่าน `npx` และคุยกันด้วย JSON-RPC 2.0):

1. เปิดไฟล์ **`.vscode/mcp.json`**
2. กด start แล้วนำ **Figma Personal Access Token** (ของคุณเอง) ไปใส่เมืิ่อ VSCode ถาม:


> **ข้อควรระวังด้านความปลอดภัย:**
> ไฟล์ `mcp.json` ถ้ามีการใช้ secret ไม่ควร commit ขึ้น git อาจจะทำแบบผมแทนคือให้ใส่ในรูปแบบ input "--figma-api-key=${input:figma-key}"

---

## 2. สตาร์ท Server และตรวจว่าเห็น Tools ทั้ง 2 ตัว (2 นาที)

1. เปิดไฟล์ `mcp.json` ใน VS Code แล้วกดปุ่ม **Start** (หรือกด `Cmd/Ctrl + Shift + P` → พิมพ์ **`MCP: List Servers`** → เลือก **`figma`** → **Start Server**)
2. เปิด Copilot Chat (โหมด **Agent**) แล้วเปิดดูรายการ Tools:
   - ใน Copilot harness: เปิด **Customizations › Tools** (หรือคลิกไอคอน Tools ในช่องแชต)
   - ตรวจว่ามีกลุ่ม **`figma`** และมี Tools 2 ตัวนี้เปิดอยู่:
     - `get_figma_data` (ดึงโครงสร้าง Layout, Text, Fills, Components จาก Figma)
     - `download_figma_images` (ดาวน์โหลดรูป PNG/SVG จาก Node ID ลงในโปรเจกต์)

---
