## 1. setup `mcp.json` ที่ folder .vscode ของโปรเจกต์ (3 นาที)

ในข้อนี้เราจะตั้งค่า MCP Server แบบ `stdio` (VS Code รันโปรเซสและคุยกันด้วย JSON-RPC 2.0) โดยเลือกได้ 2 แบบ:

1. เลือก server ที่เหมาะกับเครือข่ายของคุณ:
   - **`figma`** ใช้ `npx` และต้องดาวน์โหลดแพ็กเกจตอนเริ่ม server (แนะนำ!)
   - **`figma-local`** รัน source รุ่น `0.13.2` และ dependencies ที่เตรียมไว้ใน `vendor/figma-context-mcp/` ได้ทันที ไม่ต้องรัน install หรือ build
   - ทั้งสองวิธีต้องมี Node.js `20.20.0` ขึ้นไป; local mode ไม่ดาวน์โหลดแพ็กเกจเพิ่ม แต่ยังต้องเชื่อมต่อ Figma API เพื่อดึงข้อมูลสด
2. เปิดไฟล์ **`.vscode/mcp.json`** แล้วกด **Start** ที่ server ที่เลือก
3. นำ **Figma Personal Access Token** (ของคุณเอง) ไปใส่เมื่อ VS Code ถาม:

> **สำคัญ:** Start เพียง server เดียว (`figma` หรือ `figma-local`) เพื่อไม่ให้มี Tools ของ Figma ซ้ำกัน หากไม่มี Node.js ให้ใช้ **Offline Snapshot** ในขั้นตอนท้ายของ Lab นี้


> **ข้อควรระวังด้านความปลอดภัย:**
> ไฟล์ `mcp.json` ถ้ามีการใช้ secret ไม่ควร commit ขึ้น git อาจจะทำแบบผมแทนคือให้ใส่ในรูปแบบ input "--figma-api-key=${input:figma-key}"

---

## 2. สตาร์ท Server และตรวจว่าเห็น Tools ทั้ง 2 ตัว (2 นาที)

1. เปิดไฟล์ `mcp.json` ใน VS Code แล้วกดปุ่ม **Start** ของ server ที่เลือก (`figma` หรือ `figma-local`) (หรือกด `Cmd/Ctrl + Shift + P` → พิมพ์ **`MCP: List Servers`** → เลือก server นั้น → **Start Server**)
2. เปิด Copilot Chat (โหมด **Agent**) แล้วเปิดดูรายการ Tools:
   - ใน Copilot harness: เปิด **Customizations › Tools** (หรือคลิกไอคอน Tools ในช่องแชต)
   - ตรวจว่ามีกลุ่มของ server ที่เลือก (`figma` หรือ `figma-local`) และมี Tools 2 ตัวนี้เปิดอยู่:
     - `get_figma_data` (ดึงโครงสร้าง Layout, Text, Fills, Components จาก Figma)
     - `download_figma_images` (ดาวน์โหลดรูป PNG/SVG จาก Node ID ลงในโปรเจกต์)

## 3. ทดสอบเรียกใช้งานจริง (Smoke Test) กับหน้า Reservation (3 นาที)

เราจะทดสอบด้วยเฟรมเดียวก่อน คือหน้า **Reservation** ของ **Booking Restaurant App** (`Project หมูกระทะ`, `node-id=1439-8969`) แทนการดึงทั้งแคนวาส:

เปิด **New Chat** แล้วส่งคำขอนี้:

```text
ใช้ Figma MCP อ่านข้อมูลจากลิงก์นี้ให้หน่อย:
https://www.figma.com/design/pkCT6YDfcnEVOOTS2HIDOg/POC-FIGMA-MCP?node-id=1439-8969

ยังไม่ต้องเรียกใช้ Skill หรือสร้างไฟล์ใดๆ ให้ตอบสั้นๆ ในแชตแค่ 3 ข้อ:
1. หน้าจอนี้ชื่อ Frame อะไร และมีขนาด กว้าง x สูง เท่าไหร่?
2. ในกลุ่ม Your information มีช่องข้อมูลติดต่อกี่ช่อง ชื่ออะไรบ้าง?
3. ปุ่ม RESERVE มีสีพื้นหลัง (Hex color) และความโค้งขอบ (borderRadius) เท่าไหร่?
```

เมื่อ VS Code ถามขออนุญาตรัน Tool `get_figma_data` ให้ตรวจสอบพารามิเตอร์ (`fileKey: "pkCT6YDfcnEVOOTS2HIDOg"`, `nodeId: "1439:8969"`) แล้วกด **Allow**

**ใช้ข้อมูลต่อไปนี้ตรวจเทียบผล Smoke Test (MCP หรือ Offline Snapshot):**
- ชื่อ Frame: `Reservation` (`#1439:8969`), ขนาด `378 x 1051`
- ช่องข้อมูลติดต่อ 3 ช่องใน `Your information`: `Full name`, `Phone number`, `Email` (ไม่รวม `Notes` และตัวเลือกอื่นนอกกลุ่มนี้)
- ปุ่ม `RESERVE`: สีพื้นหลัง `#AD3F32`, ความโค้งขอบ `8px` (ขนาด `346 x 44`, rectangle `1439:8971`)

> **ถ้าเรียก MCP ไม่สำเร็จ (เช่น Error 403, 429 หรือเครือข่ายบล็อก `npx` / Figma API):**
> 1. ตรวจ Token หรือเครือข่ายตามสาเหตุ แล้วลองเชื่อมต่ออีกครั้ง
> 2. หาก `npx` ถูกบล็อกและคุณมี Node.js ให้เลือก `figma-local` ซึ่งไม่ต้องติดตั้งแพ็กเกจเพิ่ม
> 3. หากยังใช้ MCP ไม่ได้ หรือไม่มี Node.js ให้จด Error/อาการและระบุว่าใช้ **Offline Snapshot** ใน [แบบบันทึกผล](worksheet.md) อย่าบันทึก Smoke Test นี้ว่าเรียก MCP สำเร็จ
> 4. เปิด [Reservation snapshot](../docs/offline-snapshots/reservation-1439-8969-summary.yaml) เพื่อดูข้อมูลสำหรับเทียบคำตอบ Smoke Test แล้วทำตามขั้นตอน **โหมด Offline** ในข้อ 3.4 เพื่อทำภารกิจต่อ ถ้าเจอ 429 ให้เคารพ Retry-After ไม่กดเรียกซ้ำรัวๆ
