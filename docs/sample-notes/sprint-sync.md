# บันทึกคุยงานด่วน · เช้าวันจันทร์ (10:15 น.)

**ผู้เข้าร่วม:** พี่บิ้ก (PO), น้องมิ้นท์ (BA), น้องกัน (QA), น้องต้น (Dev)

- **พี่บิ้ก (PO):** ทุกคนครับ ลูกค้าแจ้งว่าฟีเจอร์แลกพอยต์ใน **Project หมูกระทะ** มีปัญหา! เวลาผู้ใช้กดปุ่มแลกสิทธิ์ซ้ำเร็วๆ แต้มโดนตัดเบิ้ล 2 รอบ อันนี้ลูกค้าจัดเป็นระดับ **SLA-Red** เลยนะ
- **น้องต้น (Dev):** โหพี่ ถ้า **SLA-Red** เดี๋ยวผมเพิ่มปุ่ม Disabled ตอนกำลังส่งคำขอ และเช็ก idempotency ที่ฝั่งโค้ดให้เลยครับ
- **น้องกัน (QA):** ได้เลยครับ เดี๋ยวกันเตรียมเคสทดสอบกดปุ่มรัวๆ (Double-click) กับเคสเน็ตช้าของ **Project หมูกระทะ** รอไว้เทสต์ให้
- **น้องมิ้นท์ (BA):** ส่วนอีกเรื่องคือ **Project ยาดมช่วยชีวิต** ตอนบ่ายนี้มิ้นท์จะสรุปกติกาการกรองหมวดหมู่ในตารางให้ค่ะ อันนี้เป็นระดับ **SLA-Amber** ทันในสปรินต์นี้แน่นอน
- **พี่บิ้ก (PO):** อ้อ ยังมีคำถามค้างอยู่ข้อหนึ่งนะ ว่าถ้าแต้มของลูกค้าติดลบไปแล้วใน **Project หมูกระทะ** ระบบควรคืนแต้มอัตโนมัติหรือให้ Admin กดอนุมัติก่อน? เดี๋ยวรอถามทีม Finance บ่ายนี้ครับ
