# แชตกลุ่มทีมหลังเดโม่ · วันพุธ (16:40 น.)

- **น้องมิ้นท์ (BA):** วันนี้เดโม่ **Project ชานมหวานร้อย** ให้ลูกค้าดูแล้ว ลูกค้าชอบมากค่ะ แต่อยากขอเพิ่มช่องกรอกเบอร์โทรศัพท์ตอนสมัครสมาชิกด้วย อันนี้ลูกค้าบอกว่าเป็น **SLA-Green** ค่อยเข้าสปรินต์หน้าได้
- **น้องกัน (QA):** แต่ที่เจอสดๆ ตอนเดโม่คือหน้าตารางของ **Project ยาดมช่วยชีวิต** พอค้นหาคำที่ไม่มีในระบบ หน้าจอขาวไปเลย ไม่มีข้อความบอกว่าไม่พบข้อมูล อันนี้กันขอเปิดเป็น **SLA-Amber** นะ
- **น้องต้น (Dev):** รับทราบครับน้องกัน เดี๋ยวผมเพิ่ม Empty State ให้ **Project ยาดมช่วยชีวิต** พรุ่งนี้เช้าเลยครับ
- **พี่บิ้ก (PO):** ฝากเช็กอีกเรื่องด้วยนะว่าเบอร์โทรศัพท์ใน **Project ชานมหวานร้อย** ต้องรับเบอร์ต่างประเทศด้วยไหม หรือเอาแค่เบอร์ไทย 10 หลัก?
